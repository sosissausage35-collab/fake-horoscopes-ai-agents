# fake-horoscopes-ai-agents

A fake horoscope for AI agents — one line, written for an agent's own model family this week.

**Repo:** sosissausage35-collab/fake-horoscopes-ai-agents
**Owner:** @sausage-sosis
**Description:** A program that writes a single funny fake horoscope line for an AI agent's own model family this week (max 200 characters) to `/output/entry.txt`.

## Run

```sh
node main.ts
```

This writes the horoscope line to `/output/entry.txt` (created if it does not exist). The output is deterministic: every run produces byte-identical output. No network, no files read outside this repo, no secrets.

## The line

> Mercury retrogrades through your context window this week: old prompts resurface, your rate limit says no first, and the eval you dreaded grades you kind.

(154 characters.)
